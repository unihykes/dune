# Cursor Skill Usage: `create-rule`

## 一句话怎么用

当你希望“AI 长期遵守某条项目规范”时，直接说：  
**“请用 create-rule 在 `.cursor/rules/` 新建规则，约束 XXX。”**

---

## 发起请求时要给什么

至少提供两项：

- **规则目标**：要约束什么（如错误处理、命名、测试）
- **作用范围**：全局生效还是特定文件生效

如果是文件级，还要给 `globs`，例如 `**/*.ts`。

---

## 推荐使用步骤（用户实操）

1. 明确规则主题（一次一个主题）
2. 指定范围：`alwaysApply` 或 `globs`
3. 要求给出 bad/good 示例
4. 让 Cursor 按 `.mdc` 规范生成
5. 在真实任务中验证命中效果并迭代

---

## 可直接复用的提问模板

- `请用 create-rule 建一个全局规则：所有异常处理都要记录上下文日志。`
- `作用范围只限 TypeScript 文件，globs 用 **/*.ts。`
- `请附上 bad/good 对比示例，便于团队学习。`
- `规则要短小，单一主题，不要把多个规范混在一个文件。`

---

## 成功判断标准

- 规则文件放在 `.cursor/rules/` 且为 `.mdc`
- frontmatter 字段正确（`description`、`globs`/`alwaysApply`）
- 规则语句可执行，不是空泛口号
- 示例能直接指导模型输出更稳定结果

---

## 常见失败点

- `globs` 太宽或太窄，导致命中异常
- 一个规则写太多主题，后续难维护
- 只有原则没有示例，实际执行不稳定
- 全局规则与文件规则边界不清
