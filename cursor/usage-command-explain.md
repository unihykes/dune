# Cursor Command Usage: `explain`

## 一句话怎么用

看不懂代码时直接说：  
**“请用 `explain` 解释这段代码，重点讲 XXX。”**

---

## 使用前你要准备什么

- 最好先选中要解释的代码块
- 或把光标放在目标函数/类内
- 告诉它你最关心的点（流程、参数、异常、返回值）

---

## 推荐使用步骤

1. 选中代码并执行 `explain`
2. 先拿“整体解释”（这段代码做什么）
3. 再追问“关键分支和边界条件”
4. 最后要一个最小输入示例验证理解

---

## 可直接复用的提问模板

- `请用 explain 解释这段函数，按“输入 -> 处理 -> 输出”讲。`
- `重点解释异常分支和错误处理策略。`
- `请给一个最小可运行示例，帮助我验证理解。`
- `请补充这段代码和上游调用关系。`

---

## 成功判断标准

- 你能复述主流程，不再只记细节
- 知道关键参数、返回值和副作用
- 明白异常路径而不只主路径
- 能用一个例子解释它为何这样写

---

## 常见失败点

- 一次选中太大范围，解释变空泛
- 不给关注点，输出不贴你的学习目标
- 只看第一轮结果，不做追问
- 把解释当“事实”，不回到代码验证
