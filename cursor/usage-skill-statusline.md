# Cursor Skill Usage: `statusline`

## 一句话怎么用

你想在 CLI 提示符上方显示会话信息时，直接说：  
**“请用 statusline 帮我配置状态栏，显示模型名和上下文占用。”**

---

## 先确定你要显示什么

建议最多 2~4 项：

- 模型名（`model.display_name`）
- 上下文占用（`context_window.used_percentage`）
- 当前目录或分支
- 会话名（有命名时）

---

## 推荐使用步骤

1. 先让 Cursor 生成最小可用配置
2. 测试显示是否正常
3. 再追加一项信息，不要一次做太复杂
4. 调整更新频率和超时，避免闪烁或卡顿

---

## 可直接复用的提问模板

- `请用 statusline 给我一个最小配置：显示模型名 + context 百分比。`
- `状态栏保持单行简洁，不要太花。`
- `请把 null/缺失字段做兜底，避免脚本报错。`
- `给一个本地 mock 测试命令，方便我验证。`

---

## 成功判断标准

- 每轮会话更新时状态栏稳定刷新
- 字段缺失时仍能正常显示（有兜底）
- 信息密度合适，不干扰输入区
- 渲染性能稳定，无明显延迟

---

## 常见失败点

- 一次堆太多信息，状态栏可读性差
- 不处理空值，导致间歇性报错
- 更新间隔太短，终端抖动
- 超时时间过长，影响交互体验
