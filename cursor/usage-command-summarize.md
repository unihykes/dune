# Cursor Command Usage: `summarize`

## 一句话怎么用

当内容很长、你要“快速抓重点”时说：  
**“请用 `summarize` 按我指定结构总结这段内容。”**

---

## 使用前建议先给的约束

- 摘要长度（如 5 条内、200 字内）
- 结构模板（背景/结论/风险/下一步）
- 用途场景（PR 描述、学习笔记、汇报稿）

---

## 推荐使用步骤

1. 先选中要总结的内容并执行 `summarize`
2. 先要“超短版”（3~5 条）
3. 再要“结构化长版”
4. 最后要“可执行下一步”

---

## 可直接复用的提问模板

- `请用 summarize，总结成 5 条以内要点。`
- `按“背景-关键变化-风险-下一步”输出。`
- `只保留会影响决策的信息，去掉复述。`
- `请区分事实和推断，并标记不确定项。`

---

## 成功判断标准

- 读完能快速做决策或安排下一步
- 有重点排序，而不是平均复述
- 风险与未决项被明确标出
- 可以直接拿去当 PR 描述或汇报提纲

---

## 常见失败点

- 不限制结构和长度，输出变冗长
- 只有结论没有行动项
- 混淆事实与推断，误导判断
- 总结过泛，无法落地到具体任务
